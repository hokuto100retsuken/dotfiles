現在のセッションの引き継ぎメモを保存する。次回セッションで「前回の続き」とすぐ言えるようにするためのもの。

## 手順

1. 保存先パスを決定する:
   - `~/.claude/projects/$(pwd | sed 's|[/.]|-|g')/handoff.md` （`/` と `.` の両方を `-` に変換する。`github.com` → `github-com`）
   - ディレクトリがなければ作成する (`mkdir -p`)

2. **既存の handoff を読む（上書きの前に必須）**

   保存先は cwd から一意に決まるので、**同じディレクトリで動く別セッションと必ず衝突する**。

   - ファイルがあれば先に読む
   - 内容に心当たりがない、または冒頭の日時が自分のセッションでの作業と合わない場合は
     **別セッションのもの**。上書きせず、主題ごとにセクションを分けて**追記**する
     （`# A. <相手の主題>` / `# B. <自分の主題>`）。冒頭にマージした旨を1行残す
   - 自分が前に書いたものだと確認できたときだけ上書きする
   - **Write ツールが「変更されている」と拒否したら、それは別セッションが今書いた合図**。
     読み直してから追記する

3. 以下の情報を収集する:
   - ブランチ名: `git branch --show-current`
   - 未コミット変更: `git status --short` の結果
   - 最新コミット: `git log -3 --oneline`
   - 今セッションでやったこと: 会話の要点を数行で
   - 次やること / 保留事項: 今セッションで未完了のタスクや、次回に持ち越す判断事項

4. 以下の形式で保存する:

```markdown
# Handoff: <YYYY-MM-DD HH:MM>   # handoff 保存時点の日時 (例: `date '+%Y-%m-%d %H:%M'`)

## ブランチ
<branch-name>

## 未コミット変更
<git status --short の出力、なければ "なし">

## 最新コミット
<git log -3 --oneline の出力>

## 今セッションでやったこと
- <箇条書き>

## 次やること / 保留事項
- <箇条書き、なければ "特になし">
```

5. **古いセクションを剪定する（追記したときは必須）**

   セクションは新しいものが先頭に積まれる。上限を決めないと際限なく育ち、
   セッション冒頭の注入コストがそのまま増える。書き終えたら以下を実行して
   **先頭5見出しだけ残し、残りは同じディレクトリの `handoff-archive.md` へ送る**。

   ```bash
   H=~/.claude/projects/$(pwd | sed 's|[/.]|-|g')/handoff.md
   A=$(dirname "$H")/handoff-archive.md
   awk -v h="$H" -v a="$A" '/^# /{n++} {print > (n<=5 ? h".new" : a".add")}' "$H"
   [ -f "$A.add" ] && cat "$A.add" >> "$A" && rm "$A.add"
   mv "$H.new" "$H"
   ```

   アーカイブに送った見出しがあれば、その数を報告に1行添える。

6. 保存完了したら、保存先パスと要点を1-2行で伝える。追記した場合はその旨も伝える。

## 注意

- **並行セッションでは上書きしない**（手順2）。自分の前回分だと確認できたときだけ上書きする。
  実績: 2026-08-20 に3セッションが順番に上書きし合い、1セッション分の内容が一度失われた
  （会話ログから復元してマージした）
- 会話の要点は簡潔に。詳細はgit logで追える
- 機密情報 (APIキー等) は書かない
- git管理外のファイル・ディレクトリに書くので、Writeツールで直接書いて良い
